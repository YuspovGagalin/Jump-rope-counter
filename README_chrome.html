Google Chrome で使うための手順

対象ファイル: jump_rope_counter_rev5_chrome-support.html

最初に：なぜファイルを直接開くと動かないのか

Google Chrome は、セキュリティ上の理由で次の2つの場合にカメラを完全に無効化します。これはブラウザ側の仕様で、アプリのコードでは回避できません。

  • ファイルをダブルクリックして開いた場合（アドレスが file:// で始まる）
  • localhost 以外のアドレスに http:// でアクセスした場合

さらに file:// では、骨格推定ライブラリ（MediaPipe）の読み込み自体も遮断されるため、動画ファイルモードも動きません。

対策は1つだけです。ローカルサーバー経由で開いてください。そのためのスクリプト serve.py を同梱しています。

1. 事前準備

Python 3 が必要です。インストール済みか確認してください。

OS確認コマンド未インストールの場合
Windowspy --versionMicrosoft Store で「Python 3」を検索してインストール
Macpython3 --version標準で入っています。無ければ brew install python3

次の2つのファイルを同じフォルダに置いてください。

  • jump_rope_counter_rev5_chrome-support.html
  • serve.py

2. PCのChromeで使う場合

最も簡単です。localhost は Chrome が例外的にカメラを許可するアドレスなので、HTTPSは不要です。

手順

  1. ファイルを置いたフォルダを開く
  2. そのフォルダでコマンドプロンプト（またはターミナル）を開く
    • Windows: フォルダのアドレスバーに cmd と入力して Enter
    • Mac: フォルダを右クリック →「フォルダに新規ターミナル」
  3. 次のコマンドを実行する 
    # Windows
py serve.py

# Mac
python3 serve.py
  4. Chrome が自動で開きます。開かない場合は http://localhost:8000/ にアクセスしてください
  5. 画面上部の「動作環境」が緑色（問題ありません）になっていることを確認する
  6. 「カメラを開始」を押し、許可ダイアログで「許可」を選ぶ
終了するには コマンドプロンプトで Ctrl + C を押してください。

3. スマホのChromeで使う場合

スマホからは localhost の例外が使えない（スマホ自身を指してしまう）ため、HTTPSが必須です。3つの方法があります。

方法A：同梱スクリプトのHTTPSモード（推奨）

PCとスマホが同じWi-Fiにつながっている必要があります。

  1. PCで次のコマンドを実行する 
    # Windows
py serve.py --https

# Mac
python3 serve.py --https
  2. 画面に表示される、スマホ用のアドレスを確認する（例: https://192.168.1.5:8443/...）
  3. そのアドレスをスマホの Chrome で開く
  4. 「接続がプライベートではありません」という警告が出ます。これは自己署名証明書を使っているためで、想定どおりの動作です。
    「詳細設定」→「(安全ではありません) にアクセスする」を選んでください
  5. 「カメラを開始」を押し、許可ダイアログで「許可」を選ぶ
つながらない場合は、PCのファイアウォールがポート 8443 を塞いでいる可能性があります。 Windows Defender ファイアウォールの通知が出たら「アクセスを許可する」を選んでください。
また、職場や学校のWi-Fiでは端末どうしの通信が禁止されている場合があります。その場合は方法Bをお使いください。

方法B：HTTPSのWebホスティングに置く

最も確実で、証明書の警告も出ません。イベントなどで複数人が使う場合はこちらを推奨します。

  1. GitHub Pages、Netlify Drop、Cloudflare Pages などの無料ホスティングにHTMLファイルをアップロードする
    （Netlify Drop はフォルダをドラッグ＆ドロップするだけで公開できます）
  2. 発行された https:// のURLをスマホの Chrome で開く

方法C：Chromeのフラグで例外登録する（検証用）

Android の Chrome 限定です。証明書を用意せずに http:// でカメラを使えるようにします。検証用の機能なので、使い終わったら元に戻してください。

  1. PCで py serve.py（HTTPSなし）を実行し、表示されたスマホ用アドレスを控える（例: http://192.168.1.5:8000）
  2. Android の Chrome のアドレスバーに chrome://flags/#unsafely-treat-insecure-origin-as-secure と入力する
  3. 入力欄に控えたアドレスをポート番号まで入力し、右のプルダウンを Enabled にする
  4. 画面下部の「Relaunch」を押して Chrome を再起動する

4. 画面上部の「動作環境」の見方

アプリを開くと、最初に環境チェックの結果が表示されます。

表示意味対応
緑：問題ありませんカメラを使える状態そのまま「カメラを開始」へ
黄：注意事項があります動作はするが推奨環境ではない「詳細」を開いて内容を確認
赤：カメラを使えません表示方法かライブラリに問題があるパネル内に表示される対処法に従う

チェックしている項目は次の5つです。

  • ブラウザ — Chrome / Edge かどうか
  • 表示方法 — file:// / http:// / https:// / localhost の判別
  • セキュアコンテキスト — ブラウザがカメラ利用を許す状態か
  • カメラAPI — navigator.mediaDevices が使えるか
  • MediaPipe — 骨格推定ライブラリを読み込めたか（インターネット接続が必要）

5. よくあるつまずき

症状原因と対処
「カメラを開始」を押しても何も起きない許可ダイアログを以前「ブロック」にした可能性があります。アドレスバー左の鍵アイコン →「サイトの設定」→ カメラを「許可」に変更し、ページを再読み込みしてください。
映像は出るが骨格の線が出ない全身（頭から足先まで）が映っていません。カメラから2〜3メートル離れてください。
「他のアプリがカメラを使用中」と出るZoom、Teams、カメラアプリなどを終了してから再試行してください。
スマホで動きがカクカクする「処理の重さ」を軽量、解像度を低、「判定グラフを表示」をオフにしてください。
縄が数えられない「赤色マスク表示」をオンにして、縄だけが水色になるよう色相・彩度を調整してください。暗い場所では赤色の検出が不安定になります。
証明書の警告が消えない自己署名証明書では毎回警告が出ます。気になる場合は方法B（HTTPSホスティング）をお使いください。

6. serve.py のオプション

コマンド動作
python3 serve.pyHTTPで起動（ポート8000）。PCのChrome用。
python3 serve.py --httpsHTTPSで起動（ポート8443）。自己署名証明書を自動生成。スマホ用。
python3 serve.py --port 9000ポート番号を変更する。
python3 serve.py --no-openブラウザを自動で開かない。

証明書は初回起動時に localhost_cert.pem と localhost_key.pem として作られ、2回目以降は再利用されます。作り直したい場合はこの2つのファイルを削除してください。
